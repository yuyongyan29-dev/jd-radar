# 追问手册:三阶段策略与话术库

## 原则

1. **每次只给当前阶段最合适的 1 条**(决策卡上),其余进折叠区。按对决策的影响力排序:工时 > 薪资构成 > 签约主体 > 团队情况。
2. **验证性提问优于是非题**:问细节让谎言难以维持,不问一个字就能糊弄的问题。
3. **阶段错配是大忌**:初聊就问穿薪资构成和加班,大概率被已读不回;Offer 前才是逐条核实的时机。
4. 所有话术是**草稿**,提醒用户按自己的语气改后再发。

## 阶段一:初聊(Boss 聊天框,目标=拿到面试+排除大坑)

**该问:** 岗位真实性、工作节奏概貌、业务方向。
**不该问:** 具体薪资构成、公积金基数、加班费(留到后面)。

- 工时(委婉版):「想先了解下团队目前的常规工作节奏,方便我评估通勤和时间安排~」
- 工时(验证版,对方答"标准工时"后):「明白!那咱们团队一般几点站会/几点下班呀?」
- 岗位真实性:「这个岗位是新增的还是补位呀?大概什么时候到岗合适?」(常年挂岗/催促异常都会在答案里露馅)
- 方向核实:「JD 里提到 X 和 Y,想确认下这个岗位当前最核心的一块是哪个?」

## 阶段二:面试(当面/视频,目标=验证团队真实状态)

- 「团队现在几个人?这个岗位进来主要接谁的工作?」(补位型高流动岗会卡壳)
- 「上一个版本/项目冲刺的时候,大家一般几点走?」(细节题,编造成本高)
- 「团队今年走了几个人?」(直接但合理,面试后期可问)
- 反问环节固定三连:汇报对象是谁 / 转正标准是什么 / 这个岗位半年内最重要的一件事是什么

**面试日观察清单(给用户的自查参考,不进评分):** 约傍晚场次顺便看工位亮灯率与在座率;留意面试官被消息打断的频率;看白板/大屏上的排期密度。

## 阶段三:Offer 前(目标=逐条核实,信源升级到 L4)

- 薪资构成:「想确认下 offer 里的结构:底薪/绩效比例、绩效打折规则、几薪、发放月份?」
- 社保公积金:「五险一金按全额基数缴吗?公积金比例是多少?」
- 签约主体:「劳动合同的签约主体是哪家公司?和招聘主体一致吗?」
- 试用期:「试用期几个月、薪资打几折、社保从入职第一个月缴吗?」
- 工时(终版核实):「入职后的考勤制度方便发我看下吗?」

**规则:以上任何一条对方拒答或含糊,标记为高风险未知项,提示用户慎签。**
