# 红旗库:安全门 + 待核验线索

## 一、安全门(硬风险,触发即置顶,不参与打分权衡)

以下任一命中:决策卡安全层置顶警示,**必须**附上命中的 JD/聊天原文、危险原因(含出处)、证据留存建议、求助路径。

| 红旗 | 典型话术/特征 | 依据 |
|---|---|---|
| 招转培 / 培训贷 | 高薪零门槛 → 面试时贬低能力 → 要求付费培训或贷款「先提升再上岗」 | 人社部等五部门 2026-05 风险提示点名的典型套路 |
| 入职收费 | 以工服费、体检费、押金、保证金、资料费等名义收钱 | 《劳动合同法》第 9 条禁止;Boss 直聘官方案例 |
| 扣押证件 | 要求押身份证、毕业证原件 | 《劳动合同法》第 9 条禁止 |
| 无薪/超长试岗 | 「先无薪试岗一周看表现」「试用期不缴社保,转正才有」 | 试用期须支付工资、依法参保 |
| 签约主体不一致 | 招聘品牌是 A 公司,合同主体是 B 公司/人力外包壳(未在 JD 说明) | 影响薪酬福利归属与维权对象;需在 offer 阶段核实 |
| 站外引流 | 用变体数字、二维码引导脱离平台沟通;岗位高薪但门槛极低、「居家可做」 | Boss 直聘安全中心公布的典型诈骗特征 |
| 异地入职/培训 | 要求先到异地参加培训或「项目地报到」 | 五部门风险提示点名(涉传销/囚禁风险,烈度最高) |
| 期权画饼抵现金 | 以「上市后期权」大幅抵扣现金薪资,且公司阶段可疑 | 用户红线选项之一,命中即警示 |

### 出事后怎么办(触发安全门时随卡输出)

1. **不付任何钱、不签任何贷款协议、不交任何证件原件。**
2. **证据留存:** 聊天记录截图(含对方账号页)、转账凭证、合同/协议照片、通话录音;保持在平台内沟通以留痕。
3. **求助路径:** 平台内举报(Boss 直聘举报入口)→ 12333 人力资源社会保障热线 → 涉及钱款损失或人身限制立即报警(110)。涉培训贷可同时向银保监/金融监管部门投诉放贷机构。

## 二、待核验线索(弱信号,只进线索区与追问清单,不扣分)

| 线索 | 解读方向 | 核验方式 |
|---|---|---|
| HR 深夜/周末高频活跃 | 团队真实工时可能偏长 | 初聊阶段追问工作节奏(见 asking-playbook) |
| 同公司其他 JD 写「抗压」「狼性」「弹性工作」 | 公司文化信号 | 扫公司主页在招岗位,面试阶段验证 |
| 同一岗位常年反复挂/多渠道重复发 | 流动率可能异常 | 追问「这个岗位是新增还是补位」 |
| 行业基率(电商运营/游戏/直播等大小周高发) | 先验概率,非该公司事实 | 直接追问工时制度 |
| 薪资区间跨度极大(如 6-20k) | 低底薪高绩效可能 | Offer 前追问底薪/绩效/提成结构 |
| 小公司薪资显著高于大厂同岗 | 结构可能有诈或岗位有隐情 | 追问薪资构成与考核标准 |
| 劳动仲裁/行政处罚记录(企查查等可查) | **可查证硬数据**:数量异常可升级进安全层 | 附查询出处 |

## 三、疑似不合理限制(单独标注,见 scoring.md)

35 岁及以下、第一学历要求、性别偏好、已婚已育偏好等——标注「疑似就业歧视性限制」,提示被筛风险,不作为对用户的否定,不自动降分。监管部门已明确关注招聘中的年龄、性别、学历歧视问题。
