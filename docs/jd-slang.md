# JD 黑话对照表(种子版)

> 用法:拆解 JD 时对照。命中≠定罪——黑话是**待核验线索**,进线索区并生成对应追问,不直接扣分。「共识强度」指中文求职社区对该解读的一致程度(高=多来源反复出现;中=常见但有反例)。欢迎 PR 补充,需附出处或案例。

| JD 原话 | 常见真实含义 | 共识强度 | 对应追问阶段 |
|---|---|---|---|
| 弹性工作制 | 只弹下班不弹上班 | 高 | 初聊问节奏 |
| 抗压能力强 | 加班多/业务压力大/人手不足 | 高 | 面试问冲刺时几点走 |
| 狼性文化 / 结果导向 | 高压考核,可能大小周 | 高 | 面试问考核制度 |
| 提供学习机会 / 成长空间大 | 薪资偏低的补偿话术 | 高 | Offer 前问薪资构成 |
| 薪资面议 | 预算低于市场价或弹性极大 | 中 | 初聊末期问区间 |
| 6-20k 式大跨度 | 低底薪+高绩效/提成 | 高 | Offer 前问底薪占比 |
| 能接受短期出差 | 出差频繁或长期驻场 | 中 | 初聊问出差比例 |
| 适应互联网节奏 / 拥抱变化 | 加班常态/方向频繁调整 | 高 | 面试问最近一次调整 |
| 有创业心态 | 一人多岗、边界模糊、可能画饼 | 中 | 面试问岗位边界 |
| 急聘 / 常年同岗重复挂 | 流动率高或岗位有隐情 | 中 | 初聊问新增还是补位 |
| 综合薪资/综合收入 XX | 含加班费/全勤/餐补后的口径 | 高 | Offer 前问底薪口径 |
| 五险一金(不写全额) | 可能按最低基数缴 | 中 | Offer 前问缴纳基数 |
