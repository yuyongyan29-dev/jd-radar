# 公司登记表(隐藏岗位雷达 · 数据侧)

许多小而美公司只在**官网招聘页**和**微信公众号**发岗位,不上 Boss/猎聘。本目录是社区共同维护的登记表,配合 `/scan`(P1 路线图)在用户本地扫描官网招聘页发现新岗位。

## 提交格式(PR)

每公司一个 YAML,放入对应城市目录(如 `companies/hangzhou/example.yaml`):

```yaml
name: 示例科技
city: 杭州
careers_url: https://example.com/careers   # 官网招聘页
wechat_mp: 示例科技招聘                      # 公众号名称(可选)
tags: [AI, 20-100人, 双休]
verified_schedule:                          # 实测工时(可选,社区线索)
  value: 双休 10-19
  source: 在职员工                           # 在职员工 | 面经 | 公开报道
  department: 产品部                         # 精确到部门,公司级请写 "全司"
  date: 2026-08                             # 信息时点
  sample_size: 1
  expires: 2027-08                          # 有效期,过期自动降权
```

## 规则

1. **实测工时是「社区线索」,不直接参与评分**——在报告线索区展示并标注元数据,由用户自行判断。
2. 每条必须带时间/来源类型/部门/样本数/有效期;无元数据的 PR 不合并。
3. **申诉与下架:** 利益相关方可开 issue 申诉,附证据;维护者 7 天内处理;争议条目挂「存在争议」标记或下架。冲突信息并列展示,不裁决。
4. 禁止人身攻击、未证实的指控、内部保密信息。只登记可公开核验或明确标注来源类型的信息。
5. 本目录数据采用 **CC BY-SA 4.0** 许可(与代码的 MIT 分离)。
